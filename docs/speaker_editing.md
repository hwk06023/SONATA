# Speaker Diarization Editing

SONATA now provides functionality to manually edit speaker diarization results after the initial WhisperX + pyannote processing. This is useful when the automatic speaker identification isn't perfect and you need to make corrections.

## Prerequisites

- A JSON transcript file generated by SONATA with speaker diarization enabled

## Using the Editor

You can edit speaker information in transcripts using the provided utility. There are two ways to use it:

### 1. Using the Test Script

The easiest way to get started is using the test script:

```bash
cd test
python edit_speaker_labels.py path/to/transcript.json [options]
```

### 2. Using the TranscriptEditor Class in Your Code

```python
from sonata.utils import TranscriptEditor

# Initialize with a transcript file
editor = TranscriptEditor("path/to/transcript.json")

# Make edits
editor.rename_speaker("SPEAKER_00", "Alice")
editor.reassign_speaker_by_time(10.5, 15.2, "Bob")

# Save the edited transcript
editor.save_transcript("path/to/output.json")
```

## Available Operations

### List Speakers

Display all speakers and transcript structure:

```bash
python edit_speaker_labels.py transcript.json --list
```

### Rename a Speaker

Change a speaker label throughout the transcript:

```bash
python edit_speaker_labels.py transcript.json --rename SPEAKER_00 Alice
```

### Merge Multiple Speakers

Combine multiple speaker labels into one:

```bash
python edit_speaker_labels.py transcript.json --merge SPEAKER_00 SPEAKER_03 --target Alice
```

### Reassign by Time Range

Change the speaker for all content within a specific time range:

```bash
python edit_speaker_labels.py transcript.json --time-range 10.5 25.3 --assign Bob
```

### Reassign by Segment Indices

Change the speaker for specific segments by their index:

```bash
python edit_speaker_labels.py transcript.json --segments 5 6 7 --assign Charlie
```

## API Reference

### TranscriptEditor Class

The `TranscriptEditor` class provides the following methods:

#### `__init__(transcript_path: str)`

Initialize the editor with a path to a transcript JSON file.

#### `get_speakers() -> List[str]`

Get a list of all speaker labels in the transcript.

#### `rename_speaker(old_speaker: str, new_speaker: str) -> int`

Rename a speaker throughout the transcript. Returns the number of changes made.

#### `reassign_speaker_by_time(start_time: float, end_time: float, new_speaker: str) -> int`

Reassign the speaker for all content between the specified time range. Returns the number of changes made.

#### `reassign_speaker_by_segments(segment_indices: List[int], new_speaker: str) -> int`

Reassign the speaker for specific segments by their indices. Returns the number of changes made.

#### `merge_speakers(speakers_to_merge: List[str], new_speaker: str) -> int`

Merge multiple speakers into a single speaker. Returns the number of changes made.

#### `save_transcript(output_path: Optional[str] = None) -> str`

Save the edited transcript to a file. If no path is provided, overwrites the original file.

## Workflow Example

1. Transcribe audio with diarization:
   ```bash
   python -m sonata.main integrated input.mp3 --diarize --hf-token YOUR_TOKEN
   ```

2. Review the transcript and identify speaker issues

3. Edit speaker labels:
   ```bash
   python test/edit_speaker_labels.py input_transcript.json --rename SPEAKER_00 Alice
   ```

4. Continue editing as needed for other speakers or sections
   ```bash
   python test/edit_speaker_labels.py input_transcript_edited.json --time-range 120.5 142.8 --assign Bob
   ```

This allows you to iteratively fix speaker diarization issues until you have an accurate transcript.
